Firebase Setup Guide

How to add your herb data directly in Firebase Console — no coding needed.

All herb information is stored directly in Firebase Firestore. You manage your data from the Firebase Console — not in any code file. This page just shows you the correct structure to follow.
1

Create a Firebase project

Go to console.firebase.google.com → click Add project → name it (e.g. herbid-iloilo) → continue. Enable Firestore Database and Storage from the left menu.

2

Paste your config into js/firebase-config.js

In Firebase Console → Project Settings → Your apps → Web app → copy the config object and paste it into js/firebase-config.js.

3

Open Firestore and create the herbs collection

In Firebase Console → Firestore Database → click Start collection → Collection ID: herbs

Each document in this collection is one herb. Use document IDs like: herb_01, herb_02, … herb_18

4

Add each herb document with these exact fields

For every herb document, add the following fields in Firestore:

Field name Type Description & example
no number Herb number. Example: 1
localName string Ilonggo/local name. Example: Alibhon
englishName string English common name. Example: Sambong
scientificName string Scientific name. Example: Blumea balsamifera
family string Plant family. Example: Asteraceae
uses array Use categories for filtering. Values must be from: fever wound pain digestive respiratory skin urinary anti-inflammatory
useTags array Human-readable use labels shown as pills. Example: ["Kidney stones", "Fever", "Diuretic"]
parts string Parts of the plant used. Example: Leaves
preparation string How to prepare the herb. Example: Boil leaves in water; drink 3x daily.
location string Where it's found. Example: Lemery, Cabatuan, Leon
emoji string Placeholder emoji until you upload a real photo. Example: 🌿
imageUrl string URL from Firebase Storage after uploading a herb photo. Leave empty at first.
5

Example — how Herb #1 (Alibhon) looks in Firestore

This is what you type into each field inside the Firebase Console for document herb_01:

// Document ID: herb_01 // Collection: herbs no (number) 1 localName (string) "Alibhon" englishName (string) "Sambong" scientificName (string) "Blumea balsamifera" family (string) "Asteraceae" uses (array) ["fever", "urinary", "pain"] useTags (array) ["Kidney stones", "Fever", "Diuretic", "Edema"] parts (string) "Leaves" preparation (string) "Boil leaves in water; drink decoction 3x daily." location (string) "Lemery, Cabatuan, Leon" emoji (string) "🌿" imageUrl (string) "" ← fill after uploading photo
Repeat this for all 18 herbs, using document IDs herb_01 through herb_18. The field names must match exactly (case-sensitive) or the website won't display them.
